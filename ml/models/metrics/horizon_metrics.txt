Limitations:
  - Historical inflow labels are mostly Normal. Very High has no examples in this dataset, so it cannot be learned and no score is reported for it.
  - A class with fewer than two training examples is unsupported. The single Exceptional day is not treated as a learned class.
  - Accuracy is high because almost every day is Normal. Model selection uses macro-F1 and minority-class recall. Accuracy is reported and is not the selection rule.
  - The 2026 test window contains almost no minority-class days, so a reliable seven-day estimate of flood recall is not possible from this split.
  - The record is monsoon-only (June-October). The gap between seasons is about 243 days. Lags use the calendar, so that gap is missing history rather than a one-day lag.
  - Jammu weather is not in the historical CSV, so it is not a supervised feature and is not used at training time.
  - Training reads the first number of a forecast range. Public alerts use the upper end of that range. Both behaviors are intentional.
  - FFD does not publish seven daily Marala discharge forecasts. These models are category classifiers, not a substitute for an official seven-day hydrograph.
