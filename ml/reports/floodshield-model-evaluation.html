Holdout scores for the seven selected horizon models. Training days are monsoon seasons 2024–2025. The test set is monsoon 2026. Accuracy was not the rule used to pick a model.

How to read the high accuracy. The 2026 labels are almost all Normal. Days +1 to +6 each contain one Low day and no Medium, High, Very High, or Exceptional day. Every selected model missed that Low day, so flood-class F1 is zero even while overall accuracy stays near 99%. Day +7 has no minority class in the test set, so its 99.42% macro-F1 is Normal only. Very High has no historical examples. Exceptional has one, which is below the two-example minimum, so neither class was trained and neither has an F1.
